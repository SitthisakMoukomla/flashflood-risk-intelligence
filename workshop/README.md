## หมายเหตุสำหรับผู้สอน

**ทำไมเริ่มด้วยบทนี้** — ผู้เรียนได้แผนที่น้ำท่วมของจริงภายในชั่วโมงแรก
โดยไม่ต้องสมัครบริการใดเลย ไม่มีใครติดค้างเพราะสมัครไม่ผ่านหรือโควตาหมด
ซึ่งเป็นสาเหตุอันดับหนึ่งที่ workshop ด้านนี้ล่ม

**จุดที่ผู้เรียนมักติด**

1. *ค้นแล้วเจอภาพ แต่ได้ 0 ไร่* — ดาวเทียมถ่ายเป็นแถบ รอบล่าสุดอาจพาดไม่ถึง
   พื้นที่ ทั้งที่ระบบค้นหาบอกว่าเกี่ยวข้อง โน้ตบุ๊กจัดการให้แล้วโดยไล่หารอบที่
   ถ่ายครอบเกิน 50% แต่ควรอธิบายว่าทำไมต้องทำ เพราะเป็นธรรมชาติของข้อมูล
2. *ตัวเลขไม่ตรงกับข่าว* — เป็นโอกาสสอนว่าเลขจากดาวเทียมกับเลขราชการ
   วัดคนละอย่าง (ขอบเขตน้ำ ณ วินาทีที่ถ่าย vs พื้นที่ประกาศภัยพิบัติ)
3. *เปลี่ยน BBOX แล้วพัง* — ถ้าย้ายไปนอกกรอบแผ่น JRC ที่ฮาร์ดโค้ดไว้
   (`seasonality_100E_20N` ครอบ lon 100-110, lat 10-20) ต้องเปลี่ยนชื่อแผ่นด้วย

**ประเด็นที่ควรย้ำ** — โน้ตบุ๊กจงใจให้ผู้เรียนเห็นว่าผลดิบจากดาวเทียมมี
แม่น้ำปนอยู่ และต้องกรองด้วยความรู้บริบท ไม่ใช่เชื่อผลสำเร็จรูป
คำถามท้ายบท ("เอาไปชดเชยเกษตรกรได้เลยหรือไม่") ออกแบบมาให้ถกกัน
