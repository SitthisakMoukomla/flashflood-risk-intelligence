## ที่มาของเอกสารชุดนี้

ระบบนี้พัฒนาผ่าน git 68 commit (ไม่นับ commit อัตโนมัติจาก cron อีก 700+)
โดยแต่ละ commit บันทึกไว้ว่าแก้อะไร ทำไม และตัวเลขยืนยันผล

เอกสารชุดนี้คือการรวบรวมสิ่งนั้นให้อ่านเป็นเรื่องเดียวกัน — ถ้าอยากดูรายละเอียด
ของการตัดสินใจใดเป็นพิเศษ ให้ดูที่ commit ตรงนั้น:

```bash
git log --format="%h %s" | grep -v "chore(data)"     # เฉพาะการพัฒนาจริง
git show <hash>                                       # อ่านเหตุผลเต็ม
```
